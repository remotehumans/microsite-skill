# Sample campaign: a fictional "many companies" run

A made-up campaign to see the gallery before doing any real research. Every company, person, fact and link is invented; links point at example.com.

- **Ashby & Rowe** is ready to send: qualified, researched, page built, outreach card written.
- **Brook & Ledger** is qualified, waiting for research and a page.
- **Carrow Tax Studio** was a no-go, with the reason saved.

Load it into your workspace and open the gallery, from the skill folder:

```bash
python3 scripts/campaign.py demo
```

```bash
node gallery/server.mjs
```

The demo copies this folder to `<workspace>/sample-campaign` and builds Ashby & Rowe's page from `examples/sample-sprint`.
