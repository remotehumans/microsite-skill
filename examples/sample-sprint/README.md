# Ashby & Rowe: a fictional sprint example

A made-up accountancy used to try the skill and to run its tests. Every fact, link and person is invented; links point at example.com. Real pages are built from a company's live website and public material (see SKILL.md).

From the skill folder:

```bash
MICROSITE_PROFILE=sample-studio python3 sprint/build_sprint.py examples/sample-sprint
```

The page is written to `examples/sample-sprint/build/ashby-and-rowe.html`.
